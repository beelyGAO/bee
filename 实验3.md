#### 16.计算每天的订单数量，并显示7天移动平均值。

```json
GET /ecommerce/_search{
{
  "size": 0,
  "aggs": {
    "daily_orders": {
      "date_histogram": {
        "field": "order_date",
        "calendar_interval": "day"
      },
      "aggs": {
        "order_count": {
          "value_count": {
            "field": "order_id"
          }
        },
        "7_days_moving_avg": {
          "moving_fn": {
            "buckets_path": "order_count",
            "window": 7,
            "script": "if (params.values == null || params.values.empty) { return 0; } else { return params.values.stream().mapToDouble(Double::doubleValue).average().orElse(0); }"
          }
        }
      }
    }
  }
}
```

### 总结

1. 使用 `PUT` 创建文档。
2. 使用 `POST` 和 `_update` 修改文档。
3. 使用 `DELETE` 删除文档。
4. 使用 `GET` 查看文档。
5. 使用 `_bulk` API 批量导入数据。
